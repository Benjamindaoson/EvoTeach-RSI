# Related Work and Novelty Boundaries

This is a **selected reading map**, not a comprehensive systematic review. Recheck publication metadata and newer papers before an academic submission.

1. **Kim, Islam & Goel (2026).** *A Metacognitive Architecture for Correcting LLM Errors in AI Agents*. AAAI/IAAI Emerging Applications. Studies metacognitive diagnosis and repair of agent knowledge errors. [AAAI paper](https://ojs.aaai.org/index.php/AAAI/article/view/41465). **Boundary:** knowledge-base repair is not novel by itself.
2. **IntelliCode (2026).** *A Multi-Agent LLM Tutoring System with Centralized Learner Modeling*. EACL System Demonstrations. Multi-agent tutoring and persistent learner representations. [ACL Anthology](https://aclanthology.org/2026.eacl-demo.10/). **Boundary:** maintaining a learner model is established prior art.
3. **Are Agents Ready to Teach? (2026).** A multi-stage benchmark for real-world teaching workflows. [arXiv](https://arxiv.org/abs/2605.14322). **Boundary:** teacher agent quality must be evaluated as pedagogy, not generic task completion.
4. **RSI-Opt (2026).** Recursive optimizer-agent procedures in model training. [arXiv](https://arxiv.org/abs/2610.32026). **Boundary:** a system modifying its own optimization procedure is not itself an original contribution.
5. **AI-ALOE at Georgia Tech.** Research on AI-assisted adult learning, transfer and adaptive expertise. [Program site](https://aialoe.org/). **Boundary:** this repository is an independent proposal, not an official project.

## Proposed differentiator — unproven

Evidence-gated, causally evaluated changes to the **teaching update mechanism** under delayed transfer, learner-cohort distribution shift, hint dependency and equal-cost comparison to first-order optimization. The central novelty and empirical superiority remain hypotheses to be tested.

## Responsible scholarly language

Say **proposes**, **implements synthetic reference**, and **will evaluate**. Do not say **proves recursive improvement**, **improves students**, **accepted at AAAI**, or **supervised by DILab** unless those statements become true and can be documented.
